INTRODUCTION

In the field of Artificial Intelligence and Data Science, collecting reliable data is the first and most important step. Web scraping is an automated method used to extract large amounts of data from websites quickly and accurately.

The Internet Movie Database (IMDb) is one of the most popular and trusted sources for movie ratings, reviews, and cinema details. The IMDb Top 250 chart highlights the highest-rated movies of all time based on votes from millions of worldwide viewers.

Manual collection of movie data like ranks, titles, release years, and ratings from 250 movies takes a lot of time and can have human errors. This project introduces an automated Python web scraper using Selenium to collect and store all 250 movie details into a structured CSV file within seconds.

PROJECT DESCRIPTION:

The IMDb Top 250 Movies Scraper is a Python-based automation tool that dynamically scrapes movie data from IMDb using Selenium and Chrome WebDriver. It retrieves movie details like title, release year, IMDb rating, and ranking from the Top 250 Movies list.

This scraper automates browser actions to handle dynamic content loading. The data extracted can be used for movie trend analysis, building recommendation engines, or for personal film databases.

The system automatically scrolls through the webpage, loads all 250 movies into memory, cleans the text using regular expressions, and exports the clean data into a CSV file format for instant analysis.

FEATURES:

1. Dynamic Movie Scraping
  • Uses Selenium to load IMDb Top 250 page and extract full content.
2. Top Movie Rankings
  • Scrapes movie rank, title, release year, and IMDb rating accurately.
3. Structured Output
  • Saves extracted data to CSV for easy access and analysis.
4. Headless Mode (Optional)
  • Can run without opening a visible browser window in the background.
5. Anti-Bot Protection Handling
  • Masks automation flags to prevent website blocks.
6. Expandable
  • Easily extendable to scrape individual movie pages for cast, genre, director, etc.

SOURCE CODE:

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.service import Service
from webdriver_manager.chrome import ChromeDriverManager
from selenium.webdriver.chrome.options import Options
import pandas as pd
import time
import re

options = Options()
options.add_argument("--start-maximized")
options.add_argument("--disable-blink-features=AutomationControlled")
options.add_experimental_option("excludeSwitches", ["enable-automation"])

driver = webdriver.Chrome(
    service=Service(ChromeDriverManager().install()),
    options=options
)

url = "https://www.imdb.com/chart/top/"
print("Opening IMDb Top 250...")
driver.get(url)
time.sleep(5)
print("IMDb website opened.")

# Scroll down to load all 250 dynamic movie rows
for step in range(1, 6):
    driver.execute_script(f"window.scrollTo(0, (document.body.scrollHeight * {step}) / 5);")
    time.sleep(1)

rows = driver.find_elements(By.CSS_SELECTOR, "li.ipc-metadata-list-summary-item")
print("Movies found:", len(rows))

data = []
for index, row in enumerate(rows[:250]):
    try:
        text = row.text.strip()
        lines = [line.strip() for line in text.split("\n") if line.strip()]
        if not lines:
            continue

        # Extract Rank and Title
        raw_title = lines[0]
        match = re.match(r"^(\d+)\.\s+(.+)$", raw_title)
        if match:
            rank = int(match.group(1))
            title = match.group(2)
        else:
            rank = index + 1
            title = raw_title
        # Extract Release Year (4-digit format like 1994, 1997)
        year = "N/A"
        text_without_title = text.replace(title, "", 1)
        year_match = re.search(r"\b(19\d{2}|20\d{2})\b", text_without_title)
        if year_match:
            year = year_match.group(1)

        # Extract IMDb Rating (e.g. 9.3)
        rating = "N/A"
        rating_match = re.search(r"\b([1-9]\.\d)\b", text_without_title)
        if rating_match:
            rating = rating_match.group(1)

        print(f"Rank: {rank} | Title: {title} | Year: {year} | Rating: {rating}")

        data.append({
            "Rank": rank,
            "Movie Title": title,
            "Year": year,
            "IMDb Rating": rating
        })

    except Exception as e:
        print("Row error:", e)

print("\n===================================")
print("IMDb TOP 250 MOVIES DATA")
print("===================================")

if len(data) == 0:
    print("No movie data found.")
else:
    df = pd.DataFrame(data)
    print(df.head())

    file_name = "imdb_top_movies.csv"
    df.to_csv(file_name, index=False, encoding="utf-8-sig")

    print("\n===================================")
    print("CSV FILE CREATED SUCCESSFULLY!")
    print("File:", file_name)
    print("Number of movies:", len(df))
    print("===================================")

time.sleep(3)
driver.quit()
print("\nProgram completed.")
